# Chromatophore Simulator

<img src="https://github.com/davewalker5/ChromatophoreSimulator/blob/main/images/skin/random-mottle.png" alt="Random Mottled Pattern" width="600">

Chromatophore Simulator is a graphical Python application inspired by cephalopod colour change. It models a field of individually controlled pigment organs that expand and contract to produce static and dynamic skin patterns, with views showing both the individual chromatophores and their combined appearance.

## Getting Started

Please see the [Wiki](https://github.com/davewalker5/ChromatophoreSimulator/wiki) for the user guide, controls and further details.
